Bootcamp EspecializATT

Desarrollo de Microservicios Seguros, Resilientes y Observables en Kubernetes con enfoque Shift Left y DevSecOps.

Kong API Gateway: Enrutamiento activo mediante Proxy Ingress.
Enfoque: 100% Práctico (Hands-On)

🎯 Objetivo Principal

Desarrollar un microservicio mediante un caso práctico incremental, aplicando Shift Left e integrando buenas prácticas de calidad de código, seguridad, pruebas y observabilidad a lo largo del SDLC.

🛠️ Metodología y Entorno

Metodología Hands-On en un laboratorio en la nube basado en Kubernetes, automatización con GitHub Actions, pipelines de CI/CD y ecocistema DevSecOps integrado.

Estructura del Temario

Módulo 1

Introducción y Fundamentos SDLC

  • Aproximación Shift Left (Seguridad temprana)
  • Ciclo de Vida del Software enfocado en DevSecOps
  • Estrategias de ramificación en Git
  • Marcos de seguridad (OWASP API Top 10, STRIDE)
Módulo 2

Diseño de Microservicios

  • Arquitectura y separación de responsabilidades
  • Composición de software (SCA / SBOM)
  • Documentación viva con OpenAPI / Swagger
  • Modelado de amenazas y Contract Testing
Módulo 3

Construcción, Pruebas y Seguridad

  • Desarrollo Guiado por Pruebas (TDD)
  • Análisis estático de código (SAST, Code Smells)
  • Gestión y estructuración segura de logs (JSON)
  • Endurecimiento de contenedores (Hardening)
Módulo 4

Validación y Pipelines CI/CD

  • Revisiones de código y Pull Requests
  • Estrategias de Integración y Despliegue Continuo
  • Construcción de Pipelines en GitHub Actions
  • Pruebas funcionales automatizadas
Módulo 5

Observabilidad Integral

  • Registros e ingesta centralizada de logs
  • Trazabilidad distribuida (Tracing)
  • Métricas operativas y Golden Metrics
  • Monitoreo de latencia, tráfico, errores y saturación
Módulo 6

Performance y Escalabilidad

  • Pruebas de rendimiento y simulación de carga
  • Escalabilidad horizontal vs. vertical en K8s
  • Estrategias de Alta Disponibilidad
  • Gestión de timeouts y tolerancia a fallas
